# React Day 1 Assignment — All 15 Questions

## Project Structure

```
src/
  components/
    Q1/   — ProfileCard (Components, Props, Composition)
    Q2/   — Reusable Button (Props, Events, Reusability)
    Q3/   — Product Card Grid (Props, Lists & Keys)
    Q4/   — Counter with Limits (useState, Conditional Rendering)
    Q5/   — Toggle Theme (useState, Conditional Styling)
    Q6/   — Login/Logout UI (useState, Conditional Rendering)
    Q7/   — Simple To-Do List (useState, Forms, Lists)
    Q8/   — Student List (Lists & Keys, Conditional Styling)
    Q9/   — Live Clock (useEffect, setInterval, Cleanup)
    Q10/  — Users Fetcher (useEffect, Fetch API)
    Q11/  — Document Title Tracker (useEffect, Dependency Array)
    Q12/  — Expensive Filter (useMemo, Performance)
    Q13/  — Prime Calculator (useMemo, Expensive Computation)
    Q14/  — Todo List (useCallback, React.memo)
    Q15/  — Counter + Child Button (useCallback, React.memo)
  App.jsx
  App.css
  index.js
```

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
